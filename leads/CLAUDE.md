# Leads folder rules

These rules apply only to files in `leads/`.

- Everyone in this folder is a made-up practice person. None of them are real.
- Never add real people or real email addresses.
- Every row needs a value in the `consent` column. Do not leave it blank.
- Never change the `@example.com` addresses. That domain is reserved and can never receive mail, so no real person is ever emailed.
